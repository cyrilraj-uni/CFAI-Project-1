# Sorting Algorithm Benchmark

A web application to compare Bubble Sort and Merge Sort performance.

## Features
- Generate random numbers for testing
- Input custom numbers
- Compare execution times of Bubble Sort vs Merge Sort
- Real-time benchmarking

## Installation
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open browser at `http://127.0.0.1:5000`

## Usage
1. Generate random numbers or enter your own
2. Click "Sort & Benchmark"
3. Compare the sorting times
