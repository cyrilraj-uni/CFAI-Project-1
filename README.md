# Sorting Algorithm Benchmark

A web application to compare Bubble Sort and Merge Sort performance, with Linear Search for finding a target value.

## Features
- Generate random numbers for testing
- Input custom numbers
- Compare execution times of Bubble Sort vs Merge Sort
- Search for a target value using Linear Search
- Real-time benchmarking

## Installation
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open browser at `http://127.0.0.1:5000`

## Usage
1. Generate random numbers or enter your own
2. (Optional) Enter a target value in the search field
3. Click "Start Benchmark"
4. Compare the sorting times and search results

## Technology used
1. Flask framework for the backend
2. Modern CSS features for smooth animations and HTML for basic structure are used
